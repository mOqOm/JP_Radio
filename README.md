# JP RADIO Volumio4 plugin
Japanese radio relay server for Volumio4

> **注意**: このプラグインは日本からのみアクセス可能です。日本国外からのアクセスは制限されています。

📖 インストール手順・開発者向け情報は [Wiki](https://github.com/mOqOm/JP_Radio/wiki) を参照してください。

## 変更履歴
### version 4.1.1(2026/08/12)
+ 2026/08/12 局ロゴ画像が横長(688x160など)のものを優先取得してしまい、albumart表示で縦伸びが目立つ不具合を修正。縦横比が正方形に最も近いもの(同率なら高解像度側)を選ぶように変更
+ 2026/08/12 タイムフリー番組表を開くたびに毎回サーバーへ問い合わせていたため表示が遅い問題を修正。まずDBキャッシュを検索し、無い日付のみサーバーへ問い合わせるように変更
+ 2026/08/12 TBS等、長時間番組を1時間ごとに区切って配信する局で、区切られた各コマの番組IDが同一のためDB登録エラーとなり番組情報が欠落する不具合を修正。番組IDに放送開始時刻を付加して一意化
+ 2026/08/12 ライブ再生中に過去方向へシークしても追っかけ再生に切り替わらない、タイムフリー再生中にシークできない、再生時間(duration)が設定されない/消えることがある不具合を修正(mpd自身のポーリングによる上書きに対する自己修復処理を追加)
+ 2026/08/13 番組表で「今日」の既に放送終了した番組が表示されないことがある不具合を修正(古い番組データの自動削除により、一部の日付のみ再取得判定に漏れていた)
+ 2026/08/13 ライブ再生から追っかけ再生に切り替えた直後、再生時間(duration)・曲情報が反映されない、またはライブの情報で上書きされ続けることがある不具合を修正
+ 2026/08/13 タイムフリー再生でシーク直後にシークバーの位置が一瞬古い位置に戻ることがある不具合を修正
+ 2026/08/13 「エリア選択」設定画面に表示される局一覧が、実際のBrowse表示(広域局を除いた県内局のみ)と一致していなかった不具合を修正
+ 2026/08/14 【重要】誤ったRadikoアカウント情報を保存すると、ログイン失敗時の例外処理漏れによりVolumioプロセス全体がクラッシュし、起動のたびに同じ場所でクラッシュを繰り返して設定画面も操作不能になる致命的な不具合を修正。ログインに失敗しても未ログイン状態として動作を継続するように変更
+ 2026/08/15 「エリア選択」に「全国」を追加。全国ネット局(ラジオNIKKEI・NHK FM等)も他の都道府県と同様に選択制にし、無条件表示をやめて設定画面とBrowse表示を一致させた
+ 2026/08/15 番組情報モーダルに番組の詳細情報(出演者情報に加え、番組の説明文)を表示するように復活
+ 2026/08/15 タイムフリー再生画面・お気に入り番組(タイムフリー)一覧に放送日付を表示するように変更。逆にライブ再生画面からは冗長な日付表示を削除
+ 2026/08/16 タイムフリー番組表の表示順を「時刻→番組名」に変更し、出演者・放送局の表示順も見やすく調整
+ 2026/08/16 お気に入り番組(タイムフリー)で、番組表の表示期間外(古い/先の)の番組がタイトル「？」のまま解決できない不具合を修正。サーバーへフォールバックして取得するように変更
+ 2026/08/16 お気に入りから選択した番組の管理モーダルに「再生」ボタンが無く、再生する手段が無かった不具合を修正
+ 2026/08/16 ライブ/タイムフリーでバラバラだったartist表示の書式を「放送局 - [日付]時刻 (Live/TimeFree)」に統一

+ 2026/07/25 プラグイン停止・アンインストール時、およびVolumioのシステム終了・再起動時に、再生キューに残った局・番組を確実に取り除くように修正

+ 2026/07/25 ライブ再生中に過去方向へシークした場合、現在放送中の番組の追っかけ再生に自動切替するように対応
+ 2026/07/25 お気に入り登録済みのタイムフリー番組を、別の週の同じ時間帯に登録し直せる機能を追加
+ 2026/07/28 FM802の局IDがフル局データとエリア別フィードで表記ゆれ(`FM802`/`802`)しており、非プレミアムユーザーのエリア判定に失敗して局一覧に表示されない不具合を修正([Issue #21](https://github.com/mOqOm/JP_Radio/issues/21))
+ 2026/07/28 番組表表示設定の表示期間(過去方向)を8日以上に設定した場合、週次番組表API(前後1週間分)がカバーしない7日より前の日付が「項目がありません」と表示される不具合を修正
+ 2026/07/28 「エリア選択」設定(エリアフリー会員向け)が、ライブ局一覧・タイムフリー局一覧・検索結果の絞り込みに反映されず、常に全国の局が表示されてしまう不具合を修正
+ 2026/07/29 「エリア選択」設定が、エリアフリー会員以外(無料プランなど)では一切反映されなかった不具合を修正。会員種別によらず、選択したエリアの局＋全国ネット局(NHKラジオなど)だけにライブ局一覧・タイムフリー局一覧・検索結果を絞り込めるように変更
+ 2026/07/29 「エリア選択」設定の変更を再起動不要でその場反映できるように改善
+ 2026/07/29 「エリア選択」でエリアを選択している場合、会員種別によらず番組表の取得対象も選択したエリア(＋全国ネット局分)だけに絞るように変更し、不要な番組表取得を削減
+ 2026/07/29 未ログイン時(局一覧が自エリアの局のみに制限される)、「エリア選択」で他エリアを選択していると自エリアの局まで一覧・番組表取得から消えてしまう不具合を修正(未ログイン時のみ自エリアを常に対象に含め、ログイン済みの場合は選択したエリアだけに厳密に絞り込む)
